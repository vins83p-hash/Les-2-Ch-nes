# 📖 Guide Simple - Les Deux Chênes

## 🚀 Comment démarrer ?

### Étape 1 : Télécharger le projet
1. Sur GitHub, cliquez sur le bouton vert **"Code"**
2. Choisissez **"Download ZIP"**
3. Décompressez le fichier sur votre ordinateur

### Étape 2 : Ouvrir l'application
1. Dans le dossier décompressé, **double-cliquez sur `index.html`**
2. Votre navigateur s'ouvre avec le menu de choix des applications
3. Cliquez sur l'application que vous voulez utiliser

---

## 🍇 Application Vinification & Traçabilité (RECOMMANDÉE)

### Accès direct
Dans le dossier `vinification/`, double-cliquez sur `index.html`

### Ce qu'elle fait
Gestion complète de la vinification :
- 📦 Enregistrer les lots de raisin reçus
- 🛢️ Gérer vos cuves avec visualisation du remplissage
- ⚙️ Noter toutes les opérations (remontage, pigeage, sulfitage...)
- 🔬 Enregistrer les analyses (densité, alcool, SO₂, pH...)
- 🔄 Créer des assemblages
- 📋 Traçabilité complète de chaque lot

### Comment l'utiliser ?

#### 1️⃣ Créer vos cuves
- Allez dans l'onglet **"Cuves"**
- Cliquez sur **"+ Nouvelle cuve"**
- Remplissez : nom, capacité, type (inox/béton/bois)
- Enregistrez

#### 2️⃣ Enregistrer un lot de raisin
- Allez dans l'onglet **"Lots"**
- Cliquez sur **"+ Nouveau lot"**
- Remplissez les informations :
  - Nom du lot (ex: "Syrah Nord 2024")
  - Type de vin (rouge/rosé/blanc)
  - Cépage, parcelle, date de récolte
  - Poids, volume, degré initial, pH
- Enregistrez

#### 3️⃣ Enregistrer une opération de cave
- Allez dans l'onglet **"Opérations"**
- Cliquez sur **"+ Nouvelle opération"**
- Choisissez :
  - La date
  - Le type (remontage, pigeage, sulfitage...)
  - La cuve ou le lot concerné
  - Les détails
- Enregistrez

#### 4️⃣ Enregistrer une analyse
- Allez dans l'onglet **"Analyses"**
- Cliquez sur **"+ Nouvelle analyse"**
- Saisissez les valeurs :
  - Densité, alcool, SO₂, pH, acidité
- Enregistrez

#### 5️⃣ Voir la traçabilité d'un lot
- Allez dans l'onglet **"Traçabilité"**
- Sélectionnez le lot dans la liste
- Vous voyez :
  - Toutes les informations du lot
  - Toutes les opérations effectuées (timeline)
  - Toutes les analyses réalisées
  - Les cuves associées

## 💾 Sauvegarde des données

**IMPORTANT** : Vos données sont sauvegardées automatiquement dans votre navigateur.

### ⚠️ Pour ne pas perdre vos données :
1. **Utilisez toujours le même navigateur** sur le même ordinateur
2. **Ne supprimez jamais l'historique ou les données de navigation**
3. **Faites des exports réguliers** (bouton Export CSV)

### 📤 Comment exporter vos données ?
Dans chaque application, cliquez sur **"Export CSV"** pour télécharger vos données en format Excel.

## 🆘 Aide

### Problème : Mes données ont disparu
- Vérifiez que vous utilisez le même navigateur
- Vérifiez que vous n'avez pas vidé le cache/historique
- Restaurez vos données depuis un export CSV si vous en avez fait

### Problème : L'application ne s'ouvre pas
- Essayez un autre navigateur (Chrome, Firefox, Edge)
- Vérifiez que JavaScript est activé dans votre navigateur
- Téléchargez à nouveau le projet depuis GitHub

### Problème : Je ne trouve pas le fichier
- Le fichier principal est **index.html** à la racine
- Pour la vinification : **vinification/index.html**
- Pour la cave : **cave-simple.html**
- Pour la gestion complète : **gestion-complete.html**
