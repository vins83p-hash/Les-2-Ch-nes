# 🌐 Comment mettre votre application en ligne (gratuit)

## 🎯 Objectif
Avoir une adresse web pour accéder à votre application depuis n'importe où.

Exemple : `https://vins83p-hash.github.io/Les-2-Ch-nes/`

---

## ✅ Ce dont vous avez besoin
- Un compte GitHub (vous l'avez déjà)
- 5 minutes

---

## 📱 Sur mobile Android (possible mais difficile)

**Je recommande plutôt d'utiliser un ordinateur** pour cette étape.

Mais si vous voulez vraiment essayer sur mobile :
1. Ouvrez Chrome sur votre mobile
2. Allez sur **github.com**
3. Demandez la **version ordinateur** du site (menu ⋮ → "Version ordinateur")
4. Suivez les étapes ci-dessous

---

## 💻 Sur ordinateur (recommandé)

### Étape 1 : Aller dans les paramètres

1. Allez sur **github.com**
2. Connectez-vous
3. Cliquez sur votre projet **"Les-2-Ch-nes"**
4. Cliquez sur **"Settings"** (Paramètres) en haut
5. Dans le menu de gauche, cliquez sur **"Pages"**

### Étape 2 : Activer GitHub Pages

1. Sous **"Source"**, sélectionnez :
   - **Branch** : `claude/setup-wine-project-2PfmR`
   - **Folder** : `/ (root)`

2. Cliquez sur **"Save"** (Enregistrer)

3. **Attendez 1-2 minutes** (GitHub prépare votre site)

4. Actualisez la page

5. Vous verrez un message vert :
   ```
   Your site is live at https://vins83p-hash.github.io/Les-2-Ch-nes/
   ```

### Étape 3 : Tester

1. Cliquez sur le lien
2. Votre application s'ouvre !
3. Vous pouvez la partager avec vos employés

---

## 🎉 C'est fait !

Maintenant vous avez une **vraie adresse web**.

**Vous pouvez :**
- ✅ Y accéder depuis votre téléphone
- ✅ Y accéder depuis n'importe quel ordinateur
- ✅ La partager avec vos employés
- ✅ L'installer comme une app sur votre téléphone

---

## 📱 Installer comme une app sur Android

Une fois que vous avez l'adresse :

1. Ouvrez l'adresse dans **Chrome**
2. Menu (⋮) → **"Installer l'application"**
3. Confirmez
4. L'icône apparaît sur votre écran d'accueil
5. Ça fonctionne comme une vraie app !

---

## ⚠️ Important

**Version actuelle vs nouvelle version :**

- L'application en ligne = version actuelle (sans connexion)
- Les nouvelles fonctionnalités (connexion, exports) = pas encore intégrées

**Pour avoir la version complète**, je dois d'abord créer le fichier intégré.

---

## 🔒 Sécurité

**Attention :** Une fois en ligne, n'importe qui peut voir l'adresse.

**Recommandation :**
- Ne partagez l'adresse qu'avec vos employés
- Une fois que j'aurai ajouté la connexion, ce sera sécurisé

---

## ❓ Questions fréquentes

**Q : C'est payant ?**
Non, GitHub Pages est gratuit.

**Q : L'adresse va changer ?**
Non, elle reste la même.

**Q : Puis-je changer l'adresse ?**
Oui, en renommant le projet, mais c'est compliqué.

**Q : Mes données sont-elles visibles par tout le monde ?**
Les données que vous saisissez restent dans votre navigateur (locales) ou dans votre Google Sheet (si synchronisation activée).

**Q : Que se passe-t-il quand je modifie des fichiers ?**
GitHub Pages se met à jour automatiquement (en 1-2 minutes).
