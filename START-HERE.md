# ▶️ COMMENCEZ ICI - Guide ultra-simple

## 📥 Étape 1 : Télécharger le projet

### Sur GitHub (là où vous êtes) :

1. **Cliquez sur le bouton vert `<> Code`** (en haut à droite)
2. **Cliquez sur "Download ZIP"**
3. **Enregistrez** le fichier sur votre ordinateur (Bureau ou Documents)
4. **Décompressez** le fichier ZIP (clic droit > Extraire)

---

## 🚀 Étape 2 : Ouvrir l'application

### Méthode SIMPLE (recommandée) :

Dans le dossier décompressé :

```
📁 Les-2-Ch-nes/
   📄 index.html  ← DOUBLE-CLIQUEZ ICI !
```

Ça va ouvrir une jolie page avec 3 choix :

1. **🍇 Vinification & Traçabilité** ← Pour faire du vin
2. **🏺 Gestion Cave Simple** ← Pour gérer une cave de vente
3. **📊 Gestion Complète** ← Pour tout gérer (domaine viticole)

Cliquez sur celle que vous voulez !

## 💾 Vos données sont-elles sauvegardées ?

**OUI !** Automatiquement dans votre navigateur.

### ⚠️ IMPORTANT pour ne pas perdre vos données :

1. Utilisez **toujours le même navigateur** (ex: toujours Chrome)
2. Utilisez **toujours le même ordinateur**
3. **Ne supprimez JAMAIS l'historique** de votre navigateur
4. **Faites des exports réguliers** (bouton "Export CSV" dans l'app)

## 🆘 Besoin d'aide ?

### Problème : Je ne trouve pas le fichier

```
Votre dossier doit ressembler à ça :

📁 Les-2-Ch-nes/
   📄 index.html           ← Page d'accueil (COMMENCEZ ICI)
   📄 cave-simple.html     ← Cave simple
   📄 gestion-complete.html ← Gestion complète
   📄 GUIDE-SIMPLE.md      ← Guide détaillé
   📁 vinification/
      📄 index.html        ← App Vinification
      📄 README.md         ← Guide vinification
```

### Problème : Ça ne s'ouvre pas

1. Essayez un autre navigateur (Chrome, Firefox)
2. Vérifiez que le fichier se termine bien par `.html`
3. Contactez-moi, je vous aide !
