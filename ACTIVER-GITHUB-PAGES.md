# 🌐 Activer GitHub Pages en 3 clics

## ⚡ Instructions ultra-simples

Suivez exactement ces étapes (ça prend 2 minutes) :

---

### **ÉTAPE 1** : Aller dans les paramètres

1. Allez sur votre projet GitHub : `https://github.com/vins83p-hash/Les-2-Ch-nes`
2. Cliquez sur **"Settings"** (Paramètres) en haut à droite

```
┌─────────────────────────────────────────────┐
│  <> Code   Issues   Pull requests   ⚙️Settings │  ← CLIQUEZ ICI
└─────────────────────────────────────────────┘
```

---

### **ÉTAPE 2** : Ouvrir GitHub Pages

Dans le menu de gauche, cliquez sur **"Pages"**

```
Settings (menu de gauche)
├── General
├── Access
├── Branches
├── ...
└── 📄 Pages  ← CLIQUEZ ICI
```

---

### **ÉTAPE 3** : Activer GitHub Pages

Vous voyez maintenant la page "GitHub Pages"

1. Sous **"Source"**, il y a un menu déroulant qui dit "None"
2. Cliquez dessus et choisissez : **`claude/enhance-vinification-traceability-uSvvy`**
3. Laissez **`/ (root)`** (ne touchez pas)
4. Cliquez sur le bouton **"Save"** (Enregistrer)

```
GitHub Pages
─────────────

Source
┌──────────────────────────────────────┐
│ claude/enhance-vinification-tra...  ▼│  ← Choisissez cette branche
└──────────────────────────────────────┘

┌────────────┐
│  / (root) ▼│  ← Laissez comme ça
└────────────┘

        [  Save  ]  ← CLIQUEZ ICI
```

---

### **C'EST FAIT ! ✅**

Vous verrez un message bleu qui dit :

```
✓ Your site is ready to be published at
  https://vins83p-hash.github.io/Les-2-Ch-nes/
```

---

## ⏱️ Attendez 2-3 minutes

GitHub construit votre site. Rafraîchissez la page après 2-3 minutes.

Le message devient **vert** :

```
✓ Your site is live at
  https://vins83p-hash.github.io/Les-2-Ch-nes/
```

## ❓ Problèmes ?

### La page ne s'affiche pas

1. Vérifiez que vous avez bien choisi la branche `claude/enhance-vinification-traceability-uSvvy`
2. Attendez 5 minutes (parfois c'est plus long)
3. Videz le cache de votre navigateur (Ctrl+F5)

### J'ai une erreur 404

1. Vérifiez l'URL (elle doit commencer par `https://vins83p-hash.github.io/`)
2. Vérifiez que vous n'avez pas de faute de frappe
3. Essayez d'ajouter un `/` à la fin de l'URL

### Je veux changer de branche

Retournez dans Settings > Pages et choisissez une autre branche (ex: `main`)
