# 🍇 Application Vinification & Traçabilité

## Comment utiliser l'application ?

### Option 1 : Sur votre ordinateur (RECOMMANDÉ)
1. Téléchargez le fichier `index.html`
2. Double-cliquez dessus pour l'ouvrir dans votre navigateur
3. L'application fonctionne immédiatement, même sans Internet !

### Option 2 : En ligne avec GitHub Pages
Si vous avez activé GitHub Pages :
- URL : `https://votre-nom-utilisateur.github.io/Les-2-Ch-nes/vinification/`

---

## 📋 Que fait cette application ?

C'est un outil complet pour gérer la vinification et assurer la traçabilité de vos vins.

### 7 modules disponibles :

#### 📊 **Dashboard**
Vue d'ensemble de votre production : lots actifs, volume total, cuves occupées

#### 🍇 **Lots de raisin**
- Enregistrer chaque réception de raisin
- Noter le cépage, la parcelle, le poids, le volume
- Enregistrer les caractéristiques (degré, pH)

#### 🛢️ **Cuves**
- Gérer vos cuves (inox, béton, bois)
- Voir le niveau de remplissage en temps réel
- Associer les lots aux cuves
- Suivre la température

#### ⚙️ **Opérations de cave**
Enregistrer toutes vos interventions :
- Remontage
- Pigeage
- Sulfitage
- Levurage
- Décuvage
- Pressurage
- Filtration
- Et bien plus...

#### 🔬 **Analyses œnologiques**
Suivre l'évolution de vos vins :
- Densité
- Degré alcoolique
- SO₂ (libre et total)
- pH
- Acidité totale

#### 🔄 **Assemblages**
- Créer vos cuvées
- Définir les proportions de chaque lot
- Documenter vos assemblages

#### 📋 **Traçabilité**
- Voir l'historique complet de chaque lot
- Timeline de toutes les opérations
- Historique des analyses
- Traçabilité totale du raisin à la bouteille
