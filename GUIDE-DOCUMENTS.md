# 🗂️ Guide de la Gestion des Documents - Les Deux Chênes

## 🎯 C'est quoi ?

Un endroit pour **stocker tous vos documents** viticoles :
- 🔬 Analyses de laboratoire
- 📄 Certificats (Bio, HVE, AOP)
- 🧾 Factures
- 📝 Contrats
- 📷 Photos

**Tout au même endroit, organisé et facile à retrouver !**

## ✨ Pourquoi c'est utile ?

- ❌ Difficile de retrouver une analyse

- ❌ Risque de perdre des documents

- ✅ Recherche rapide
- ✅ Liés aux clients
- ✅ Toujours accessibles

---

## 📤 Comment ajouter un document

### Méthode simple

1. **Allez dans l'onglet "Documents"** (en bas)

2. **Cliquez sur "+ Ajouter un document"**

3. **Remplissez le formulaire :**
   - Fichier : Choisissez votre fichier (photo, PDF, etc.)
   - Type : Analyse labo / Certificat / Facture / etc.
   - Client : (optionnel) À qui c'est lié
   - Date : Date du document
   - Description : (optionnel) Notes

4. **Cliquez sur "Ajouter"**

**C'est fait !** Votre document est sauvegardé.

## 🔍 Comment retrouver un document

### Méthode 1 : Recherche par nom

1. Allez dans l'onglet "Documents"
2. Tapez dans la barre de recherche
3. Les résultats s'affichent automatiquement

**Exemple :** Tapez "analyse" → Vous voyez toutes les analyses

### Méthode 2 : Filtrer par type

1. Cliquez sur le menu déroulant "Type"
2. Choisissez (Analyses / Certificats / Factures...)
3. Seuls ces documents s'affichent

### Méthode 3 : Filtrer par client

1. Cliquez sur le menu déroulant "Client"
2. Choisissez un client
3. Seuls ses documents s'affichent

---

## 👁️ Comment voir un document

### Voir une miniature

Les documents s'affichent en grille :
- **Photos** → Vous voyez la photo
- **PDF / Word** → Vous voyez une icône

### Ouvrir en grand

1. **Cliquez sur le document**
2. Une grande fenêtre s'ouvre
3. **Photos** → Vous voyez l'image en grand
4. **PDF** → Vous pouvez lire le PDF
5. **Autres** → Bouton pour télécharger

---

## 📥 Comment télécharger un document

**2 méthodes :**

### Méthode 1 : Depuis la liste
1. Cliquez sur l'icône **📥** (télécharger)
2. Le fichier se télécharge

### Méthode 2 : Depuis la prévisualisation
1. Ouvrez le document (clic dessus)
2. Cliquez sur **"📥 Télécharger"**
3. Le fichier se télécharge

**Le fichier va dans votre dossier "Téléchargements"**

---

## 🗑️ Comment supprimer un document

1. Trouvez le document
2. Cliquez sur l'icône **🗑️** (poubelle)
3. Confirmez la suppression

**Attention : Action définitive !**

---

## 🏷️ Lier un document à un client

**Pourquoi ?**
Pour retrouver facilement tous les documents d'un client.

**Comment :**
1. Lors de l'ajout du document
2. Choisissez le client dans le menu déroulant
3. Le document sera lié à ce client

**Exemple :**
- Analyse du vin de M. Dupont
- → Liez au client "Dupont"
- → Vous retrouverez cette analyse dans les documents de Dupont

## 💾 Où sont stockés les documents ?

### Sur mobile / ordinateur local
**Dans votre navigateur** (localStorage)

**Avantage :** Rapide, gratuit, hors-ligne
**Inconvénient :** Si vous changez de téléphone, vous perdez les documents

### Avec Google Drive (bientôt)
**Sur votre Google Drive** (dans le cloud)

**Avantage :** Ne perdez jamais rien, accessible partout
**Inconvénient :** Nécessite connexion internet

---

## 📏 Limites

### Taille des fichiers
**Maximum : 10 Mo par fichier**

Si votre fichier est plus gros :
- Compressez-le
- Ou stockez-le ailleurs (Drive, Dropbox)
- Et mettez juste le lien dans la description

### Nombre de documents
**Illimité** (mais attention à la place sur votre appareil)

### Types de fichiers acceptés
- ✅ Images : JPG, PNG, GIF, WEBP
- ✅ PDF
- ✅ Word : DOC, DOCX
- ✅ Excel : XLS, XLSX
- ❌ Vidéos (trop lourdes)
- ❌ Fichiers exécutables (dangereux)

## 💡 Conseils d'utilisation

### 1. Nommez bien vos fichiers

**Bon exemple :**
- `Analyse_Vin_Rouge_2024_Mars.pdf`
- `Certificat_Bio_2024.pdf`
- `Facture_Heliocuivre_Avril_2024.pdf`

**Mauvais exemple :**
- `Document1.pdf`
- `IMG_1234.jpg`
- `Sans titre.pdf`

### 2. Ajoutez une description

Ça aide à retrouver plus tard !

**Exemple :**
- "Analyse du vin rouge cuvée prestige 2024, réalisée par Laboratoire Provence"

### 3. Liez aux clients

Systématiquement pour :
- Analyses de leurs vins
- Contrats
- Factures

### 4. Organisez par date

Mettez la vraie date du document, pas la date d'upload.

**Exemple :**
- Analyse du 15 mars → Date : 15/03/2024
- (Même si vous l'ajoutez le 20 mars)

### 5. Sauvegardez ailleurs aussi

**Important :** Gardez une copie sur :
- Votre ordinateur
- Google Drive
- Clé USB

**Ne comptez que sur l'application pour les documents importants.**

## ❓ Questions fréquentes

**Q : Mes documents sont-ils sauvegardés automatiquement ?**
Oui, dès que vous ajoutez un document.

**Q : Puis-je modifier un document ajouté ?**
Non, mais vous pouvez le supprimer et en ajouter un nouveau.

**Q : Que se passe-t-il si je supprime un document par erreur ?**
Il est perdu définitivement. Faites attention !

**Q : Puis-je ajouter plusieurs documents d'un coup ?**
Pas pour le moment, un par un seulement.

**Q : Les documents sont-ils synchronisés avec Google Sheets ?**
Pas pour le moment. Ils restent locaux.

**Q : Puis-je accéder aux documents hors-ligne ?**
Oui, tant qu'ils sont dans votre navigateur.

**Q : Combien de place ça prend ?**
Ça dépend de vos documents. Un PDF = ~500 Ko, Une photo = ~2 Mo
